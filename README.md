# Second Brain

Second Brain helps you learn from your own life.

This repository currently contains Phase 1 of the hackathon MVP: a polished UI-only prototype for an AI-powered personal memory and reflection system.

## Phase 1 Scope

- Next.js App Router frontend
- TypeScript and Tailwind CSS
- shadcn-style local UI primitives
- Framer Motion micro-interactions
- Lucide React icons
- Recharts dashboard visuals
- Mock memory capture, voice recording, search, AI answers, insights, processing, and graph states

No real backend, auth, database, AI calls, transcription, file upload, or vector search is implemented in this phase.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Next.js.
